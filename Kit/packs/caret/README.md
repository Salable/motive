# Caret

> **Audience:** anyone assembling a companion for a CLI agent session.
> **Prerequisites:** none. Run it with `MOTIVE_SPRITE=Kit/packs/caret/sprite swift run motive-demo`.
> **Source of truth:** `pack.json` beside this file; the art is generated by `scripts/make-kit-art.py`.

A terminal caret — a tall block standing on an underscore — for the **Claude
Code** profile in
[../../../docs/reference/STATE-PROFILES.md](../../../docs/reference/STATE-PROFILES.md#claude-code).
Same nine states as [Pip](../pip/README.md) and the same grid; the difference is
the silhouette and who is meant to drive it. Hooks fire on real events, so this
pack expects the fuller vocabulary.

| | |
| --- | --- |
| Drives | `idle`, `thinking`, `working`, `waiting`, `review`, `failed`, `sleeping` |
| Also draws | `waving`, `jumping` |
| Triggers | `wave`, `jump` |
| Atlas | `sprite/spritesheet.png` — 1024×1152, 8 columns × 9 rows of 128×128 |
| Licence | MIT |

The Codex CLI profile fits this pack too — it drives a subset (no `thinking`,
because nothing tells you a turn has begun until it ends).

## Using it

```sh
cp -R Kit/packs/caret/sprite Apps/MyCompanion/Sprites/caret
```

Then wire the hooks: the event-by-event table is in
[STATE-PROFILES.md](../../../docs/reference/STATE-PROFILES.md#claude-code), and
[../../../docs/guides/ASSEMBLE-AN-APP.md](../../../docs/guides/ASSEMBLE-AN-APP.md)
is the whole assembly.

The one thing to get right for this pack is flicker: `PreToolUse` and
`PostToolUse` fire fast in a tool-heavy turn, and re-requesting a state the
companion is already in is free (`.noChange`), so let `working` hold rather than
switching it off between calls.
