# Pip

> **Audience:** anyone assembling a companion app, or drawing over one.
> **Prerequisites:** none. Run it with `MOTIVE_SPRITE=Kit/packs/pip/sprite swift run motive-demo`.
> **Source of truth:** `pack.json` beside this file; the art is generated by `scripts/make-kit-art.py`.

A round, plain-shapes companion for the **general product lifecycle** — the
profile in
[../../../docs/reference/STATE-PROFILES.md](../../../docs/reference/STATE-PROFILES.md#general-product-lifecycle).
Pip is what you reach for when your *own* app drives the companion: a build, an
upload, a sync, a long query.

| | |
| --- | --- |
| Drives | `idle`, `working`, `waiting`, `review`, `failed` |
| Also draws | `thinking`, `sleeping`, `waving`, `jumping` |
| Triggers | `wave`, `jump` |
| Atlas | `sprite/spritesheet.png` — 1024×1152, 8 columns × 9 rows of 128×128 |
| Licence | MIT |

## Using it

Assembling an app around it is
[../../../docs/guides/ASSEMBLE-AN-APP.md](../../../docs/guides/ASSEMBLE-AN-APP.md).
The short version: copy `sprite/` into your app and never read out of this
directory at runtime.

```sh
cp -R Kit/packs/pip/sprite Apps/MyCompanion/Sprites/pip
```

## Repainting it

Every cell is drawn by `scripts/make-kit-art.py`, so edits made here are
overwritten the next time it runs. Copy the pack first, then repaint — the
tracing grid in
[../../components/sprites/grid-template/](../../components/sprites/grid-template/)
has the same cells with the guides visible, and
[../../../docs/guides/SPRITE-DESIGN.md](../../../docs/guides/SPRITE-DESIGN.md)
is the walkthrough.
