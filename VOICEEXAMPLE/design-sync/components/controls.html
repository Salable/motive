Rules

One primary-filled control class per surface — never two competing accents in the same card.
Disabled controls stay visible (never hidden), at reduced opacity.
Radios and switches apply INSTANTLY. The one exception: Port/Make-public edit DRAFTS and only take effect via the "Save and restart" button (or Enter in the port field) — because a live rebind briefly drops the listener, it shouldn't happen on every keystroke.
