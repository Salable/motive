Type + density

TalkBox uses a small, semantic scale — not a numeric type ramp. Two sizes, one registered display font, and a color (not a size) for secondary text.

TalkBox size="display", mono_font_id → Pacifico
The wordmark only. <text size="display"><span mono="true">{'TalkBox '}</span></text> — TalkBox has no other mono text, so theme.typography.mono_font_id is safely repointed at the embedded Pacifico-Regular.ttf for this one span. The trailing space in the span gives the script's swash room so the final glyph doesn't clip.
Body — rows, card text, buttons, field values default size
Secondary — previews' muted variant, durations, section headers, hints foreground="text_muted", same size as body
