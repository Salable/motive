Keyboard map

Media-app conventions. v2 removed the quick-entry field (agent-first: enqueue via REST, tray, or Requeue) — so ⌘N is gone, and every remaining key is queue/nav, never text entry.

KeyActionScope
SpacePause/resume (plays next when idle)app fallback (on_key)
↑ ↓Move queue selectionapp fallback
⌘↑ ⌘↓Reorder the selected itemapp fallback
⌫ / DelRemove the selected itemapp fallback
⌘ESkip the current utterance — doubles as Decline while a reply is awaitedmenu + shortcut
⌘KClear Queue (asks first) — also resolves a stuck awaiting replymenu + shortcut
⌘,Switch to the Settings tab (and raise the window)shortcut
EnterSend the reply draftreply composer's text field only

Rule unchanged from the pre-v2 HIG stage: while any text field is focused, typing wins — the app-level keys above structurally never fire (SDK precedence). Every key action is redundant with a visible control, menu item, or tray row.
