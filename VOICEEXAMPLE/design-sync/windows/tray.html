Glance and one-click control; managing/reordering stays in the main window. The icon itself carries state (an SDK patch was needed — StatusItemState had no icon channel before this project added one, preserved as docs/sdk-patches/dynamic-tray-icon.patch).

Rules

"Reply" is the tray's own escape hatch: raises the window onto the Queue tab (same command as Show Queue) — the one state most likely to need a nudge when the app isn't in view.
"Play" is one-button transport: idle → starts playback; already playing → skips to the next item (arms play_requested so the next item starts even with autoplay off).
"Show Queue" / "View Settings" both switch tabs AND raise the window — macOS doesn't activate an app when its status-item menu is clicked, and this SDK has no window-front seam for TEA apps, so the model spawns osascript asking System Events to raise our own pid (one-time Automation permission; works for unbundled native dev binaries too).
Pause/Skip/Clear are NOT in the tray — the window is one click away via Show Queue, and they remain in the app menu, shortcuts, and transport.
